# Atelier Finestre - demo

Sito statico dimostrativo per un progetto generico nel settore di finestre e porte.

## Contenuti

- Brand e testi fittizi, senza recapiti o localita aziendali reali.
- Illustrazioni SVG create per la demo.
- Modulo simulato: non invia e non salva dati.

Personalizza nome, prodotti, servizi e contatti soltanto con informazioni fornite e verificate per il progetto di destinazione.
